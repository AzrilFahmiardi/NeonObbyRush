# Neon Obby Rush

Game platformer obby 3D bertema cyber synthwave neon. Pemain mengendalikan **Rush** yang harus melewati 5 stage penuh rintangan di Neon Realm hingga mencapai Portal Finish di puncak Glitch Tower.

- **Engine:** Unreal Engine 5.8 (Blueprint saja)
- **Platform:** PC Windows, single player
- **Mata kuliah:** UTS Praktikum Pengembangan Game, D-IV TRPL, Sekolah Vokasi UGM

## Cara membuka
1. Pasang Git LFS, lalu clone repo ini.
2. Klik dua kali `NeonObbyRush.uproject` (UE 5.8).
